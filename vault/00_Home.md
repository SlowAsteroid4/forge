# Forge — Base de Conocimiento

**Forge** es la plataforma de métricas y gamificación del equipo Yapsi: **Forge Ops** (consola del PM: pulso, cierres, forecast, costos) + **Forge Arena** (capa RPG para devs: SP, leaderboard, achievements). Este vault es el cerebro del proyecto: el **por qué** de cada decisión, el dominio canónico y las lecciones — conocimiento que no vive en el código.

> Audiencia: **solo el PM**. Incluye datos sensibles (costos/salarios).
